# mini-rag-app
Testing App with MiniRaga

## Requirements

-Python 3.8 or later 

## Install Python using Miniconda

This project uses Python managed via Miniconda. Follow the steps below to set up your environment.

### 1. Download Miniconda
Download the installer for your OS from the [official Miniconda page](https://docs.conda.io/en/latest/miniconda.html) and choose Python 3.x version.

### 2. Install Miniconda

**macOS / Linux:**
```bash
bash Miniconda3-latest-MacOSX-x86_64.sh   # macOS
bash Miniconda3-latest-Linux-x86_64.sh   # Linux
